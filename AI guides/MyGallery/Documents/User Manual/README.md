# User Manual

The User Manual for MyGallery. It holds, for each version:

- `<stem> v<version> draft NN.md` the Markdown source, which is the source of truth
- `<stem> v<version> - format-config.json` the cover fields and any layout rule
- `<stem> - changelog.md` one row per change, with its reason and evidence

`version_doc.py` runs on this folder.
