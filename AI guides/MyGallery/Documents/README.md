# Documents

One folder per document, named for its type: `User Manual/`, `Quick Start/`, `Admin Guide/`, `Troubleshooting/`, `Release Notes/`, `Glossary/`, `File Reference/`.

The folder is named for the type, and the files inside it carry the document's full name: `Documents/User Manual/Acme Reporting User Manual v1.0 draft 01.md`.

`init_project.py <project> --product "<name>" --document "<type>"` adds one.
