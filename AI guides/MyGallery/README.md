# MyGallery

Everything written about MyGallery: the source material, the evidence, the planning the documents share, the documents themselves, and the releases.

- `Inputs/` the source material, kept as it arrived
- `Source pack/` the verified evidence, and the baseline the next release diffs against
- `Planning/` the documentation plan, the outline, terminology, open questions
- `Documents/` one folder per document, such as `User Manual/`
- `Deliverables/` a release, once the user has confirmed it final
