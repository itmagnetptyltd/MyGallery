# Planning

What the whole document set is built from, and what is still open:

- `documentation-plan.md` the readers, the tasks, the delivery, the document set
- `outline.md` the chapters and the task topics beneath each
- `terminology.md` one term per thing, read before each topic is drafted
- `open-questions.md` each missing fact and assumption, with its owner
- `capture-list.json` each figure to capture, where no source pack holds one

These are shared, because a manual and its quick start describe one product and must not disagree.
