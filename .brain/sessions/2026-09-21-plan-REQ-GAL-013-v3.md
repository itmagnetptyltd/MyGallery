Slice 7, UAT visual — the one id left before it is Done. The v3 criteria come
from FB-0005 (CHG-0010, CHG-0012, CHG-0013), clarified by the client's third-
and fourth-round answers of 2026-09-21.

Gate: `close-slice.js --gate REQ-GAL-013` passed — slices 1-6 are Done.
Dependencies REQ-GAL-001 and REQ-GAL-007 are `verified`.

## What must be true

c1-c6 are unchanged from v2 and already built and tested. They need their
pins moved, not new code.

1. **c1** Starting an Upload opens the Upload popup, where files are chosen.
2. **c2** An empty Gallery shows a control that opens the popup.
3. **c3** The popup's close control sits inside the popup, at its top right.
4. **c4** Closing the popup before anything is uploaded adds no Photo.
5. **c5** A chosen file shows as a preview image, not only a filename.
6. **c6** Thirty chosen files show thirty previews.

New in v3:

7. **c7 — larger.** On a screen at least 1280 pixels wide, the popup is wider
   than the 680 pixels it was delivered at.
8. **c8 — close control.** The popup's close control has the same size,
   border and colours as the Larger view's: a 36-pixel white circle with a
   white edge and dark ×. Today it is 32 pixels and uses a smaller ×. It stays
   at the top right (c3).
9. **c9 — border.** The whole popup has a border of the same width, style and
   colour as the Larger view panel's: `1px solid #fff`. Today it has none.
10. **c10 — buttons.** Choose files and Upload have the same shape, border and
    colours as the Larger view's Save description button: a rectangle
    outlined in white, not a circle. Today both use the header's grey-outlined
    `.upload` look.

## Approach

CSS and markup only. The server, the API and `app.js` behaviour are untouched.

- **`src/mygallery/static/app.css`**
  - `.upload-popup`: widen it to `width: min(900px, 92vw)` with
    `max-width: 900px`, and give it `border: 1px solid #fff`.
  - **Close control:** move the look shared by the two close controls into one
    rule, `.upload-popup-close, .larger-view-close`: size, border, background,
    colour, font size and hover. `.upload-popup-close` then keeps only its
    absolute top-right position. The two cannot drift apart again.
  - **Buttons:** move the white-outlined rectangle into a named class,
    `.outline-button`, that `button.save` also uses. `.save` names a purpose
    (saving a description), not a look, so reusing that class for Upload would
    mislead.
- **`src/mygallery/templates/gallery.html`**
  - The Upload button gets `class="outline-button"` instead of `upload`.
  - The Choose files `<span>` inside `.upload-pick` gets `outline-button`.
    Its focus ring stays on `.upload-pick:focus-within`, since the real control
    is the hidden file input.
  - Save description changes from `class="save"` to `class="outline-button"`.
- **The header's "Upload photos" button does not change.** It is not in the
  popup, and no criterion covers it. It keeps `.upload`.

## Decisions this forces

- **900 pixels.** The client said "increase", with no number. c7 only asks for
  more than 680. I chose 900 because slice 9 (REQ-GAL-015@v2) will make each
  preview as wide as the description box, and a wider popup makes those
  previews worth looking at. It is a taste call, not an ADR, and easy to
  change. Correct it here if you want a different width.
- No ADR needed. There are no new dependencies and no architectural change.

## What I am unsure about

- **White on white in the light theme.** On a light-theme PC, `#fff` borders
  and outlines on the `#fff` panel are invisible. The Larger view already has
  this problem, and c8-c10 say "the same as the Larger view", so this plan
  copies it faithfully. If the client uses light mode, "a white line" will not
  show. The client's screenshot is dark mode. This is worth one line in the
  pull request, not a change to the criterion.
- **REQ-GAL-019@v2 shares c8 word for word.** It is slice 8 and not in this
  plan. The same close-control test could also carry
  `@covers REQ-GAL-019@v2`, which would let slice 8 close without a second
  test. I will not add that unless you say so.
- **REQ-GAL-015@v2** (full-width previews) is slice 9 and not in this plan.
  Widening the popup here is compatible with it but does not deliver it.
- Nothing in `.brain/rejected/` touches this.
