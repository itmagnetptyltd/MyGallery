# docs/

Working notes and reference files. **Not** requirements, changes, or feedback.

| Path | Holds |
|---|---|
| `commands.yaml` | Words saved with `/note` (polish, "just do this") |
| `ref/` | Uploaded files — screenshots, emails, PDFs. Serial prefix `001-` |

The dashboard **Working** tab reads both. Promote anything that must be agreed
scope with `/feedback-capture` / `/change-record`.
